## 2023-10-14 - Delegate Scroll Animations to Compositor\n**Learning:** Using React state and effects to update a progress bar based on window scroll events causes continuous re-renders and main thread layout thrashing, which is a major performance bottleneck for UI.\n**Action:** Use framer-motion's useScroll along with CSS transform (scaleX) to delegate animations directly to the compositor, bypassing the React render cycle entirely.
