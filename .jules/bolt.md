## 2026-08-01 - DOM manipulation in useEffect preventing static rendering
**Learning:** Next.js static rendering/SSR is blocked by layout thrashing when visual lengths (like stroke dash offsets) are parsed via DOM calls (`.querySelectorAll`, `.getAttribute`) in `useEffect`. This approach causes both build/runtime failures and poor rendering performance on initial load due to double rendering.
**Action:** Precalculate coordinate distances mathematically within a `useMemo` hook during the render phase. Pass these precalculated distances declaratively to SVG elements via inline styles to remove imperative DOM queries entirely, ensuring SSR compatibility. Also ensure default array props in component signatures are extracted to constants to preserve referential equality across renders.
