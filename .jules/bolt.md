## 2025-03-09 - [Refactor SVG Animations away from useEffect]
**Learning:** When generating complex SVG components in React (like network diagrams with animated connections), using `useEffect` to query the DOM via `querySelectorAll` and calculate dynamic lengths or assign CSS animations manually creates unnecessary performance bottlenecks and forces double-renders on initial load. It violates React's declarative paradigm and blocks Server-Side Rendering or static generation capabilities because `getAttribute` lengths cannot be determined on the server.
**Action:** Instead of mutating `.style` imperatively after paint, move distance calculations (e.g. `Math.sqrt(...)`) to `useMemo` hooks calculating values during the render cycle. Expose those values directly inside JSX using the `style` prop, mapping custom logic directly via generic CSS Custom Variables (using `@ts-expect-error` or `CSSProperties` overrides to bypass TS errors) allowing deterministic client-side rendering.
