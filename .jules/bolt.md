## 2025-03-24 - Precalculate Geometric Paths Instead of Querying DOM in Next.js
**Learning:** Using `useEffect` alongside `.querySelectorAll` to measure layout distances and attach animation offsets causes synchronous layout thrashing during the React mount phase. Furthermore, because it relies heavily on the `window` or actual DOM node existence, it prevents components from properly server-side rendering (SSR), and breaks hydration loops in Next.js leading to severe Time-to-Interactive (TTI) degradation.
**Action:** Always precalculate coordinate distances and connection logic mathematically in Javascript during the render phase via `useMemo`. Pass those precalculated values declaratively straight to elements as CSS custom variables (e.g. `style={{ '--path-length': len }}`). This avoids touching the DOM imperatively, executes optimally during static analysis/SSR, and completely eliminates layout thrashing.
